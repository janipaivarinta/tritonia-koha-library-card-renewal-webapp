# AI Transparency Statement

## Project

Tritonia Koha Library Card Renewal — v1.0

## Use of artificial intelligence

OpenAI ChatGPT has been used as an assistance tool during the development and documentation of this project. Assistance has included proposing and reviewing code changes, troubleshooting integration behavior, and drafting or editing technical documentation.

AI-generated suggestions are not treated as independently verified implementations. The project maintainer is responsible for deciding which suggestions to adopt, reviewing changes, testing functionality, and approving releases.

## Verification and limitations

Selected Koha REST API operations and email submission have been tested individually. These tests do not establish that the entire renewal workflow, eligibility rules, security controls, or production deployment have completed acceptance testing.

AI assistance does not replace code review, security assessment, testing, or applicable institutional approval processes.
